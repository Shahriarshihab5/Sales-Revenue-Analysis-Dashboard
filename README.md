Sales & Revenue Analysis Dashboard
Microsoft Excel | Advanced Analytics | Data Modeling
A multi-sheet Excel workbook analyzing FY 2024 sales performance across product categories, regions, and salespersons — built to demonstrate advanced Excel skills including Power Pivot, DAX, lookup functions, and scenario modeling.

Dashboard Preview
Open Sales_Revenue_Analysis_Dashboard.xlsx in Microsoft Excel to interact with all sheets and live formulas.

Project Objectives
Analyze revenue, gross profit, and unit sales across 36 transactions spanning 12 months. Build dynamic lookup tools to retrieve product and salesperson data on demand. Summarize performance by category, region, and individual salesperson using formula-driven pivot tables. Model future revenue scenarios using What-If Analysis with adjustable assumptions.

Workbook Structure
Raw Data — 36 sales records with formula-driven Revenue, COGS, Gross Profit, and Profit Margin columns.
Lookup Table — Live XLOOKUP, VLOOKUP, and HLOOKUP demo. Change the product name and all values update instantly.
Pivot Summary — SUMIF, AVERAGEIF, and RANK summaries by Category, Region, and Salesperson.
Monthly Trend — Month-by-month revenue vs target with MoM growth percentage and a line chart.
What-If Analysis — 12-month scenario planner. Adjust 5 assumption cells to simulate different revenue outcomes.
Dashboard — Executive summary with KPI cards and cross-sheet linked tables.

Excel Skills Demonstrated
Data Modeling and Formulas: Power Pivot and DAX measures for revenue trend modeling. XLOOKUP, VLOOKUP, HLOOKUP for dynamic cross-sheet data retrieval. SUMIF, AVERAGEIF, IFERROR, INDEX/MATCH, and RANK functions. Calculated fields and field-level aggregations.
Analysis and Reporting: PivotTable-style summaries using formula arrays. KPI tracking across Revenue, Gross Profit, Profit Margin, and MoM Growth. What-If Analysis with Goal Seek logic and Scenario Manager structure. Conditional formatting using color scales and traffic-light rules (On Track / Below Target).
Dashboard Design: Multi-sheet linked workbook with live cross-references. Industry-standard color coding — blue for hardcoded inputs, black for formulas. Line chart comparing Actual Revenue vs Target across 12 months.

Dataset Overview
Period: January to December 2024
Regions: Dhaka, Chittagong, Sylhet, Rajshahi
Product Categories: Electronics, Software, Accessories
Salespersons: 4
Total Records: 36 transactions, 361 live formulas

How to Use

Download and open Sales_Revenue_Analysis_Dashboard.xlsx in Microsoft Excel (2019 or later recommended).
Start on the Dashboard sheet for an executive overview.
Go to Lookup Table and change cell I4 to any product name to see XLOOKUP, VLOOKUP, and HLOOKUP update live.
Go to What-If Analysis and change the blue assumption cells (C4 to C8) to model different revenue scenarios.
Add new rows to Raw Data and all Pivot Summary and Dashboard figures update automatically.
